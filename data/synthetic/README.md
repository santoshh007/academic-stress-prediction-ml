# Synthetic Data — README

## What this folder contains

`student_stress_synthetic_1000.csv` — a **synthetic** dataset of 1,000 academic
stress survey responses, structurally mirroring the real survey collected for
this project.

## Origin

This dataset was **generated by a Large Language Model (LLM)** to test whether
the machine learning pipeline described in the main project scales from 39 real
responses to a larger sample size.

## Important — what this data is NOT

- ❌ Not real survey responses
- ❌ Not from real undergraduate students in Nepal
- ❌ Not derived from or validated against real students
- ❌ Not usable for making claims about academic stress in Nepal

## What it IS used for

- ✅ Testing whether the ML pipeline scales to larger n
- ✅ Comparing model behavior between small-sample (n=39) and larger-sample (n=1000) settings
- ✅ Demonstrating that the pipeline code is correct at scale
- ✅ Validating the finding that poor real-data performance is due to sample size, not methodology

## Related files

- `../raw/student_stress.csv` — the real 39 survey responses
- `../processed/` — cleaned and engineered data derived from the real responses
- `../../notebooks/` — the real-data pipeline (primary analysis)
- `../../notebooks_synthetic/` — the synthetic-data pipeline (validation analysis)

## Ethical note

Results derived from this dataset are **never** presented as findings about
real students. All real-data findings appear exclusively in the primary
`notebooks/` directory.
